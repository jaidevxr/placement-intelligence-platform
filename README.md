# Universal Company-Wise Placement Intelligence Platform (2025–2026)

A complete, production-ready placement preparation and intelligence platform built with React, Vite, Tailwind CSS, Lucide Icons, Recharts, and Supabase.

---

## 🚀 Features

- **Company Intelligence**: 115+ indexed tech, IT, product, and fintech companies (Apple, Google, Microsoft, Amazon, TCS, Infosys, Wipro, Cognizant, Accenture, Deloitte, HCLTech, Paytm, Samsung R&D, etc.).
- **Real LeetCode Company Data**: Sourced directly from GitHub LeetCode company-wise repositories (`snehasishroy/leetcode-companywise-interview-questions`, `hitarth-gg/visor-leetcode`).
- **Direct Working Solve Links**: Every single coding problem has a direct **Solve →** button linking to `https://leetcode.com/problems/...`.
- **Striver-Style DSA A2Z Sheet**: 11 steps, 128+ problems, interactive checkboxes with `localStorage` progress persistence, step progress bars, and direct LeetCode/GFG solve links.
- **2025–2026 PYQ Database**: Filter past placement questions by year (2026, 2025, 2024), company, and difficulty with step-by-step solutions and explanations.
- **Quantitative & Logical Aptitude**: Full bank of real math questions (Probability, Permutations & Combinations, Trains, Boats & Streams, Time Speed Distance, Percentages, Profit & Loss, Ratio, Averages) with full step-by-step explanations.
- **BBD Campus Intelligence Module**: Dedicated BBD University (BBDU / BBDNITM) placement drive tracker with 18+ drive records, LPA packages, roles, and campus advice.
- **Dark Terminal Aesthetics**: Styled inspired by modern dark mode platforms (`overrrides.com`), featuring high-contrast typography, color-coded difficulty badges, and clean layout grids.

## 🛠 Local Setup & Development

```bash
# 1. Clone the repository
git clone https://github.com/jaidevxr/placement-intelligence-platform.git
cd placement-intelligence-platform

# 2. Install dependencies
npm install

# 3. Create .env file
cp .env.example .env

# 4. Start dev server
npm run dev
```

Visit `http://localhost:5173` in your browser.
